## ✨ Features

- **Interactive 181-Frame Ocean Canvas**: Real-time cursor-tracking perspective animation across Polynesian sea voyages.
- **Cinematic Soundtrack & Atmosphere**: Deep turquoise ocean gradients, glowing UI accents, and smooth typography.
- **Sleek GSAP Timelines**: Elegant entry animations, interactive buttons, and responsive modal transitions.
- **Static Export Ready**: Fully pre-rendered and optimized for GitHub Pages edge deployment.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 App Router (Static Export)
- **Canvas & Rendering**: HTML5 Canvas 2D Context with aspect-ratio cover scaling
- **Animations**: GSAP
- **Styling**: Tailwind CSS v4

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/cyber-atharv/moana-cinematic-voyage.git

# Navigate into project directory
cd moana-cinematic-voyage

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
